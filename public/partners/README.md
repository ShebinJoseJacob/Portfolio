# Partner Logos

Place the official partner logo files in this directory.

## Required Logo Files:

1. **arduino-logo.svg** - Arduino official logo
   - Download from: https://www.arduino.cc/en/trademark
   - Preferred: SVG format, white or light colored version

2. **edge-impulse-logo.svg** - Edge Impulse official logo
   - Download from: https://www.edgeimpulse.com/
   - Preferred: SVG format, white or light colored version

3. **particle-logo.svg** - Particle official logo
   - Download from: https://www.particle.io/
   - Preferred: SVG format, white or light colored version

4. **viam-logo.svg** - Viam official logo
   - Download from: https://www.viam.com/
   - Preferred: SVG format, white or light colored version

5. **blues-logo.svg** - Blues official logo
   - Download from: https://blues.com/
   - Preferred: SVG format, white or light colored version

6. **dfrobot-logo.svg** - DFRobot official logo
   - Download from: https://www.dfrobot.com/
   - Preferred: SVG format, white or light colored version

## Logo Specifications:

- **Format**: SVG (preferred) or PNG with transparent background
- **Color**: White or light-colored logos work best on dark backgrounds
- **Size**: Logos will be displayed at max 180px width × 80px height
- **Aspect Ratio**: Maintain original aspect ratio

## Tips:

- For best quality, use SVG format when available
- If using PNG, use at least 360px width for retina displays
- Ensure logos have transparent backgrounds
- Use official brand assets when possible to comply with trademark guidelines
